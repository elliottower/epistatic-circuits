\section{Auditing circuit discovery proxies}
\label{sec:auditing}

The sparse Walsh recovery in the previous section provides exact
pairwise interaction coefficients for a 20-head IOI circuit. We use
these coefficients as ground truth to evaluate three families of proxy
measures: weight-space geometry, path patching, and MIB faithfulness.
Each proxy captures a different aspect of circuit structure, and the
correlations between them reveal which aspects each method preserves and
which it discards.
